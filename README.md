단양고등학교의 일일 급식 정보(조식, 중식, 석식)를 쉽고 빠르게 확인할 수 있는 웹 사이트입니다. 깔끔한 UI와 함께 칼로리 정보, 공유 기능, 다크 모드 등을 제공합니다.

[🏠 서비스 바로가기](https://seongjin-cafeteria-site.netlify.app)

---

## ✨ 주요 기능

- **📅 일별 급식 조회**: 날짜 선택기를 통해 원하는 날짜의 급식 메뉴를 확인할 수 있습니다.
- **🍱 식단 정보 제공**: 조식, 중식, 석식 메뉴와 각 식단의 칼로리 정보를 상세히 보여줍니다.
- **🚫 알레르기 정보 필터링**: 메뉴 이름 뒤의 복잡한 알레르기 유발 물질 번호를 자동으로 제거하여 가독성을 높였습니다.
- **🌗 다크 모드 지원**: 사용자의 눈 건강을 위한 다크 모드와 라이트 모드 전환 기능을 제공합니다.
- **📋 급식 공유 기능**: 현재 선택된 날짜의 전체 식단 정보를 클립보드에 복사하여 간편하게 공유할 수 있습니다.
- **📱 반응형 웹 디자인**: 데스크탑은 물론 모바일 기기에서도 최적화된 화면을 제공합니다.

## 🛠 기술 스택

### Frontend
- **HTML5 / CSS3**: 구조 설계 및 반응형 스타일링
- **JavaScript (Vanilla JS)**: 동적 데이터 바인딩 및 UI 로직 처리

### API & Tools
- **NEIS 오픈 API**: 교육행정정보시스템(NEIS)의 급식 정보 데이터 활용
- **Netlify**: 웹 사이트 호스팅 및 배포

## 🚀 시작하기

이 프로젝트는 별도의 빌드 과정 없이 정적 파일로 구성되어 있습니다.

1. 저장소를 클론합니다. (실제 GitHub URL로 변경하여 사용하세요)

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. `index.html` 파일을 브라우저로 엽니다.

또는 제공된 [Netlify 링크](https://seongjin-cafeteria-site.netlify.app)를 통해 바로 접속할 수 있습니다.
